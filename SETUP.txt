ULTIMATE MASTER VIDEO DATABASE — PHONE APP (PWA)

WHAT THIS IS
This is the new phone-entry system. It does NOT require the Windows PC to be on.
Records are stored in the phone browser's local storage.

ONE-TIME SETUP
A PWA must be opened from an HTTPS web address (or localhost). The PC-started
server is intentionally no longer used.

Recommended simple deployment:
1. Create a repository on GitHub for this small phone app.
2. Upload all five app files to the repository's root.
3. Enable GitHub Pages for the repository, using the main branch/root folder.
4. Open the resulting HTTPS Pages address on the phone.
5. Use the browser's "Add to Home Screen" / "Install" command.

DAILY USE
1. Open the Video Database app on the phone.
2. Enter Title, Service and Watch Date.
3. Tap Save Record.
4. Repeat for every title watched. The PC can be completely off.
5. When back at the PC, tap Import Phone Records in the Windows database program.
6. Select Phone_Video_Records.json from the phone's Files/Downloads or wherever
   you saved/shared the exported file.
7. Review the records and choose Import to Database.

IMPORTANT
The app does not write to the Windows database while you are away. The export
file is the handoff between the phone and PC.

The current app stores only Title, Service and Watch Date. Season/Episode fields
will be added as a separate database enhancement so they are handled consistently
in the master database, search, manual entry and phone entry.
